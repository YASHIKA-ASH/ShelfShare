# ShelfShare Software Requirements Specification (SRS)

## Project Name
ShelfShare

## Problem Statement
Students purchase expensive textbooks that are used for only one semester, while many books remain unused and local bookstores struggle with declining sales.

## Objective
Develop a digital platform where students can rent textbooks from local bookstores and verified students at affordable prices.

## Users
- Student
- Bookshop Owner
- Admin

## Functional Requirements
- User Registration/Login
- Search Books
- View Book Details
- Rent Books
- Return Books
- Inventory Management
- Rental History

## Non-Functional Requirements
- Secure authentication
- Responsive design
- Fast search
- Scalable database
- Data privacy
